# Project Rules

Project: Sports Court Booking System

Tech Stack:
- Node.js
- Express.js
- MongoDB
- React
- JWT Authentication

Coding Rules:
- Use async/await
- Never use callback style
- Use MVC architecture
- Use service layer
- Proper error handling
- Use mongoose transactions
- Clean code
- Don't modify existing APIs without asking
- Always explain major changes


Analyze the complete project.

Read AGENTS.md.

Understand the backend architecture.

Do not change any existing APIs.

If frontend is missing, create a React + Vite frontend inside the frontend folder.

Integrate it with the existing backend.

Keep the project production ready.
